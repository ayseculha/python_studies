# Week 1

Introduction to Python: user input, arithmetic and conditional statements.

## Topics

- Reading user input with `input()` and converting types with `int()`
- Arithmetic operators, including integer division (`//`) and modulo (`%`)
- Comparison and logical operators (`>`, `==`, `and`)
- Conditional statements: `if`, `elif`, `else`, including nested conditions

## Files

The exercises are ordered from simple to more complex.

| # | File | Description |
|---|------|-------------|
| 01 | `01_comparison_operator.py` | Evaluates a single comparison expression |
| 02 | `02_add_two_numbers.py` | Adds two numbers entered by the user |
| 03 | `03_place_values.py` | Splits a 5-digit number into its digits |
| 04 | `04_pass_fail_basic.py` | Pass/fail check using `if`/`else` |
| 05 | `05_pass_fail_variable.py` | Pass/fail check using a result variable |
| 06 | `06_compare_numbers.py` | Compares two numbers with `if`/`elif`/`else` |
| 07 | `07_password_strength.py` | Rates a password by its length |
| 08 | `08_letter_grade.py` | Converts a numeric grade to a letter grade |
| 09 | `09_find_minimum.py` | Finds the smallest of three numbers |
| 10 | `10_find_largest.py` | Finds the largest of three numbers |
| 11 | `11_ticket_price.py` | Calculates a ticket price with nested conditions |

## How to run

Make sure Python 3 is installed, then run any file from the `week1` folder:

```bash
cd week1
python3 01_comparison_operator.py
```
